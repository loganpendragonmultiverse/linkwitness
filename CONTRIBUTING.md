# Contributing

Contributions are welcome through reviewed pull requests. Open an issue first for scope-changing work. Install `.[dev]`, add focused tests, and run `ruff format --check .`, `ruff check .`, `mypy src`, `pytest`, and `python -m build` before submitting.

Pull requests must explain the user problem, approach, limitations, and security or privacy impact. Automated checks do not replace maintainer review. Do not include private manuscripts, credentials, or production data in issues or fixtures.
